# Copter_path_fined_and_mission_generation
Обработка osm-карт для поиска пути при помощи алгоритма A star и последующей генерации полетного задания в qground control

## Запуск скриптов рекомендуется проводить из стандартной папки
cd /home/%user_name%/DroneNavigation/Scripts

- Обработка OSM-файла и построение карты проходимости

  - python3 ReadOSM.py

- Модуль обработки OSM-данных и построения Occupancy Grid.

  - python3 OSMHandler.py

- Поиск пути

  - python3 PathFinder.py

- Генерация файла миссии для QGroundControl. Имя файла сгенерируется и покажется автоматически скриптом, здесь в примере "path_20260815_180807.txt"

  - python3 mission_generator.py --input-file /home/andrey/DroneNavigation/Plans/path_20260815_180807.txt


В рамках данной работы решается задача построения энергооптимального (или кратчайшего по дальности) маршрута для беспилотного летательного аппарата (БПЛА) в статической городской среде. В качестве исходных данных используется векторная карта в формате OpenStreetMap (OSM, созданная ранее в главе 2), которая одновременно служит основой для трёхмерной симуляции в среде Gazebo. Это гарантирует геометрическую согласованность между виртуальной средой и навигационной картой.
Основным алгоритмом глобального планирования выбран A* (A-star) – один из наиболее эффективных методов поиска кратчайшего пути на графе или дискретной сетке. 

Общая схема обработки включает следующие этапы:
1. Парсинг OSM-файла и извлечение полигонов зданий с их высотами (модули «ReadOSM.py» и «OSMHandler.py»).
2. Построение двумерной карты проходимости (Occupancy Grid) с учётом буфера безопасности.
3. Трансформация географических координат (WGS84) в метрическую систему UTM для корректного расчёта расстояний.
4. Запуск алгоритма A* на сетке (модуль «PathFinder.py»).
5. Обратное преобразование найденной последовательности ячеек в географические координаты и экспорт в формат «.plan» (совместимый с QGroundControl, модуль «mission_generator.py»).

Необходимые библиотеки и их функциональное назначение

Ниже приведён минимальный набор библиотек, обеспечивающих все этапы обработки: парсинг OSM, преобразование координат, растеризацию, поиск пути и экспорт. Установка выполняется через пакетный менеджер pip из стандартного репозитория Python. Для систем Ubuntu 22.04 предварительно требуется установить системные зависимости (python3-rtree, python3-geopandas) через apt.



Установка и проверка. Для воспроизведения окружения достаточно выполнить в терминале:
sudo apt update
sudo apt install python3-pip python3-rtree python3-geopandas
python3 -m pip install --upgrade pip
python3 -m pip install numpy matplotlib shapely pyproj osmium
python3 -m pip install colorama

Проверка установки:
python3 -c "import numpy, matplotlib, shapely, pyproj, osmium, colorama; print('All OK')"

### Важно! Скрипты работают на любой системе, на которой есть интерпретатор python и QGroundControl, однако проверку можно провести только в настроенной симуляции или при загрузке на реальный квадрокоптер.
